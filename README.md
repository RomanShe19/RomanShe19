### Delivery Manager · Implementation Manager · IT Project Manager

Delivery Manager с опытом запуска и масштабирования технологических сервисов в FinTech, loyalty, retail и HoReCa.

Координирую взаимодействие клиентов, разработчиков и партнёров, управляю сроками, рисками, зависимостями и ожиданиями стейкхолдеров. Техническая подготовка помогает мне глубже понимать интеграционные сценарии, точнее формулировать требования и эффективнее взаимодействовать с командами разработки.

Последние два года развиваю практические компетенции в Python, API, AI и автоматизации. Представленные ниже репозитории — учебные и pet-проекты, демонстрирующие мою техническую грамотность и способность самостоятельно прототипировать решения.

## 🧭 Профессиональный профиль

- **Delivery Management:** планирование и контроль поставки, управление сроками, рисками, зависимостями и блокерами
- **Implementation:** сбор и формализация требований, onboarding, интеграционное тестирование и go-live
- **Stakeholder Management:** координация клиентов, технических команд, партнёров и подрядчиков
- **Process Improvement:** анализ процессов внедрения, выявление узких мест и стандартизация запусков
- **Technical Communication:** REST API, системные интеграции, SQL, постановка задач команде разработки
- **Domains:** B2B IT, FinTech, QR-платежи, loyalty, retail и HoReCa

## ⭐ Избранные проекты

### 🔹 [ClientOrder](https://github.com/RomanShe19/ClientOrder) `Full-Stack` `Deployment`

Самохостируемое приложение для приёма заказов, разработанное с учётом ограниченных ресурсов VPS.

Реализованы JWT-аутентификация, поведенческая аналитика, reverse proxy, лимиты ресурсов для контейнеров и автоматическое обновление приложения.

*Stack: FastAPI, React 18, TypeScript, PostgreSQL, Docker Compose, Nginx, SQLAlchemy 2*

### 🔹 [AI Bot Generator](https://github.com/RomanShe19/telegram_bot_generator) `LangChain` `Code Generation`

Прототип многоэтапного LLM-пайплайна, который преобразует текстовое техническое задание в структуру Telegram-бота на aiogram и проверяет синтаксис создаваемого кода.

*Stack: LangChain, ProxyAPI, aiogram 3.x, Pydantic*

### 🔹 [AI Agent with Tools](https://github.com/RomanShe19/AI_Agent_with_tools) `Agents` `Function Calling`

Прототип AI-агента с подключаемыми инструментами для веб-поиска, работы с погодой, файлами и терминалом. Поддерживает интерфейсы CLI и Telegram, контекстную память и логирование действий.

*Stack: LangChain, OpenAI API, aiogram, duckduckgo-search*

### 🔹 [Parser + Telegram Bot](https://github.com/RomanShe19/Parser) `Parsing` `Automation`

Асинхронный инструмент сбора данных с управлением и просмотром результатов через Telegram-бота. Приложение контейнеризировано с помощью Docker.

*Stack: asyncio, Playwright, curl-cffi, aiogram 3.x, SQLite, Docker*

### 🔹 [Monitoring Stack](https://github.com/RomanShe19/monitoring) `Observability` `Infrastructure`

Учебный стенд для сбора, визуализации и анализа логов приложений. Проект помог изучить базовые принципы observability и диагностики сервисов.

*Stack: Docker, Grafana, Loki, Promtail, Python logging*

### 🔹 [AI Assistant Telegram Bot](https://github.com/RomanShe19/AI_Assistant_TGbot) `AI Assistant` `Telegram`

Telegram-бот с контекстной памятью, несколькими пользовательскими ролями, генерацией изображений и учётом потребления токенов.

*Stack: aiogram 3.x, OpenAI API, SQLAlchemy, asyncpg*
